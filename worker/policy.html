Trophies Tracker

Privacy Policy
Last updated: November 2026

1. Introduction

Trophies Tracker ("the Application") is an independent application that allows users to view their Steam and PlayStation game libraries and the related achievements and trophies. This Privacy Policy describes what data is collected, how it is used, and what rights the user has.

The Application is not affiliated with, authorized by, sponsored by, or endorsed by Steam, Valve Corporation, Sony Interactive Entertainment, PlayStation, or any other gaming platform. The PlayStation connection is unofficial: it works through the same sign-in and services that Sony's own apps use, which Sony has not published for third parties and may change or block at any time.

2. Data Collected

The Application collects only the following data, strictly necessary for the service to function:

2.1 Data provided via Steam login

  • Steam ID — the unique identifier of the Steam account, obtained through Steam's OpenID authentication.
  • Steam username (persona name) — the public display name of the account.
  • Steam avatar — the public profile picture.

2.2 Data provided via PlayStation login

  • PlayStation online ID — the public name of the PlayStation Network account, when it can be read.
  • Sony sign-in tokens — issued by Sony after the user signs in on Sony's own page. The Application never sees the user's Sony email or password.

2.3 Game data

  • List of games in the user's Steam library, and of PS4 and PS5 games with trophies on the user's PlayStation account.
  • Achievements and trophies related to each game: names, descriptions, grade, whether they are hidden, how rare they are, and whether and when the user earned them.

2.4 Data NOT collected

The Application does not collect:

  • Email addresses or contact information.
  • Payment or financial data.
  • Geolocation data.
  • Biometric data.
  • Third-party data for advertising or profiling purposes.
  • Device advertising identifiers.

3. How Data Is Used

Collected data is used exclusively for the following purposes:

  • Displaying the user's game libraries, achievements and trophies within the Application.
  • Synchronizing game, achievement and trophy data with Steam and PlayStation Network servers.
  • Saving game data locally on the device for offline access.

Data is not used for advertising, profiling, or behavioral analysis. Data is not sold, transferred, or shared with third parties, except as strictly necessary for the service to function (Steam, Sony, Cloudflare).

4. How Data Is Stored

4.1 Proxy server (Cloudflare Worker)

Every request to Steam or PlayStation Network goes through a proxy server (a Cloudflare Worker). It stores very little:

  • Steam: the user's Steam ID is stored on the proxy associated with an anonymous session token (UUID). The token expires after 30 days, after which it is automatically deleted, and it is deleted at once when the user logs out. During sign-in, a one-time code that expires after 60 seconds is also kept.
  • PlayStation: nothing is stored. The proxy receives the sign-in code or the tokens in the body of an encrypted request, passes them on to Sony, and returns the answer.
  • Request limits: to protect the service from abuse, the number of requests is limited for each client. The limit uses the client's IP address or a one-way hash of the session token as a key that Cloudflare's rate limiter keeps only for the length of the counting window (about a minute). The developer does not store it.
  • Logs: the proxy does not record request logs. Session tokens, Sony tokens and Steam or PlayStation identifiers are never placed in request addresses.
  • Public data cache: Cloudflare may keep, for up to a day, the answers of Steam that are the same for every user (for example the list of achievements of a game). They contain no personal data.

4.2 Local device storage

Game data, achievements, trophies, and application preferences are saved exclusively on the user's device via a local database. No game data is transmitted to or stored on external servers owned by the developer.

The user's Steam ID, username, and avatar, and the PlayStation online ID with the date the link expires and the time of the last synchronization, are stored locally on the device for session persistence. The Steam session token and the PlayStation renewal token (valid for about 10 days) are kept in the secure storage of the device (iOS Keychain, Android Keystore). Sony's short-lived access token is kept in memory only. This data is deleted upon logout or uninstallation.

4.3 Security

  • The session token replaces the Steam ID in all client-server communications, reducing exposure of the user's identifier.
  • Session tokens and Sony tokens travel in request headers or bodies, never in request addresses. The only thing that passes through an address is the one-time Steam sign-in code, which works once, for 60 seconds, and only together with a secret that stays in the Application.
  • All communications are conducted exclusively over encrypted HTTPS connections.

5. Third-Party Services

5.1 Steam / Valve Corporation

Authentication is handled through Steam's OpenID system. Library and achievement data is retrieved via Steam's public APIs. Steam's Privacy Policy and Terms of Service apply.

5.2 Sony / PlayStation Network

The user signs in on Sony's own page, opened in the device's browser. Game and trophy data is retrieved through the same services used by Sony's own apps. Sony's privacy policy and terms of service apply to the PlayStation account and to the data it provides.

5.3 Cloudflare

The proxy server is hosted on Cloudflare Workers. Cloudflare may collect anonymous technical data according to its own Privacy Policy.

5.4 Ko-fi

The Application contains a link to the developer's page on Ko-fi, where the user can choose to support the project. It opens in a browser view; the Application sends no data to Ko-fi, and Ko-fi's own privacy policy applies on its pages.

6. User Rights

  • Access — the user can view their own data at any time directly within the Application.
  • Deletion — by logging out of Steam, the session token is invalidated and local data is deleted. By unlinking PlayStation, the tokens and the games synchronized from it are deleted from the device; Sony's renewal token also expires on its own after about 10 days. Uninstalling the Application removes all local data from the device.
  • Portability — game data is directly accessible through Steam and PlayStation Network.

7. Children

The Application is not intended for users under the age of 13. The developer does not knowingly collect personal data from children. If you believe a child has provided personal data through the Application, please contact the developer to request its deletion.
